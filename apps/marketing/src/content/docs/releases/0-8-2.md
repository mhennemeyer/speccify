## Terminal appearance and multiline prompts

The terminal now follows Light, Dark or System appearance, including its controls,
cursor and ANSI colours. Adjust the font from **8–32 px** using **A− / A+** or
Settings. Changes apply to running terminals and persist across windows.

**Shift+Enter** inserts a new line in Codex and Claude prompts; **Enter** submits.
Previously, both keys sent the same input. Other shells and custom host bindings
may handle the modified key differently.

## Notice waiting questions

Terminal notification signals and common permission prompts can display an in-app
notice, including when the terminal pane is hidden. Jump directly to the source
terminal. Optional system notifications draw attention when its window is inactive;
Settings includes a test button. Repeated redraws are deduplicated.

Free-form questions are not always detectable. Operating-system permissions and
Do Not Disturb can suppress system notifications. Notices never answer a question
or approve a command automatically.

## Editable Codex and Claude settings

Open **Agents** in the dashboard or **Agent-Einstellungen** from a project or
workspace. Settings are grouped, searchable and accompanied by help. Complex
values have JSON editors; the full TOML/JSON source remains accessible.

The **Selbstständig arbeiten** profile proposes settings that reduce approval
interruptions. Review the draft and save explicitly. Existing unknown values and
unrelated settings are preserved; invalid values and conflicting external edits
are rejected. Restart the host to apply changes. Host versions, account access,
project overrides and managed policies still determine what is available.

See the [terminal and agent settings guide](/app/terminal-settings/) for details,
including Windows sandbox setup and configuration precedence.

## Update or install

- **From 0.8.1:** check **Environment → Updates**, download 0.8.2, then install
  when open editors, drafts and running processes are closed. Installation restarts
  Speccify; downloading alone does not.
- **From 0.8.0 or earlier:** install the new version once from the
  [download page](/download/). These older versions lack the updater verification key.
- **Linux deb/rpm:** update through your package manager. In-app Linux updates
  apply to AppImage.

Packages cover macOS Apple Silicon, Windows x64 and Linux x86_64/arm64.
macOS packages are Developer ID signed and notarized. Update packages use verified
signatures on all four targets. Windows code signing is separate; SmartScreen may
still warn. Downloads are on the [0.8.2 release page](https://github.com/mhennemeyer/speccify/releases/tag/v0.8.2).

## Verification and scope

The terminal and settings checks passed the browser and native test suites,
including Windows CI. On macOS, real Codex 0.154.0 and Claude 2.1.273 terminals
retained two input lines without submitting them. Actual notification delivery and
installation in the Windows VM and on Linux remain separate platform acceptance
checks. The itsdcloud work for 0.9.0 is not part of this update.

The published 0.8.1 was successfully updated to the public 0.8.2 on macOS:
download, signature verification, installation through the update dialog and
restart all passed. All four open windows were restored, and the installed
0.8.2 retained its valid Developer ID signature. All four public update URLs
and the complete update manifest were also verified.
