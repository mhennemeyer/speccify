## Mermaid diagrams in documents

Mermaid code blocks now render as diagrams in playbooks and the shared desktop
Markdown viewer. Rendering is bundled with the app and needs no external service.
Diagrams follow the light or dark theme. Their source remains available; invalid
syntax shows an error and the original code instead of hiding the document.

This fixes the plain-code display in 0.7.0, including on Windows. Flowchart and
sequence rendering are covered by a Windows Chromium regression test.

## Shared knowledge across a workspace

Skills, tools, MCP definitions and playbooks appear in shared lists with source
labels and filters. Editing, importing and creating entries stay bound to the
selected folder. Listing an MCP definition does not automatically connect it to
your terminal host; review and configure that connection explicitly.

The file navigator also includes ordinary folders and files in the workspace
root. You do not need to turn resource folders into Git repositories.

## Portable spec registers

Bind logical register IDs to local checkouts and show their specs on one board.
The same portable manifest works with the desktop app and the separately hosted
web board. A designated checkout owns writes; conflicting copies remain visible
as warnings. Specs can reference multiple repositories and branches.

The workspace board also exposes register setup and sync where applicable.
Existing project files are not silently migrated into a shared register.

[Workspace guide](/app/workspaces/) · [Web-board setup](/web-board/)

## Draft playbooks

Mark ideas and research with `status: draft`. Drafts remain visible and editable,
but do not become development instructions until explicitly activated. Existing
playbooks without a status field retain their previous active behavior.

## Download and update

Download the new installer from the [release page](https://github.com/mhennemeyer/speccify/releases/tag/v0.8.0)
or the [download page](/download/). On Windows, close Speccify and run the
new x64 installer to update the existing installation.

- macOS: Apple Silicon, macOS 11+, signed and notarized.
- Windows: x64 setup executable and MSI; not code-signed, so SmartScreen may warn.
- Linux: x86_64 and arm64, AppImage, deb and rpm; requires WebKitGTK 4.1.

Automatic updates are not configured in this release. The updater integration
exists, but the signing setup, Windows update artifacts and safe restart flow
still need to be completed and verified. This release uses manual installation.
