## Questions you can read — and copy from

When the agent asks a question, it often contains exactly what you have to
carry into a terminal: a command, a path, a repository name. Until now the
question was one block of text and those pieces had to be selected by hand.

- The question box in the spec inspector renders the question **as Markdown**:
  paragraphs, lists, bold text and code blocks. Single line breaks in the
  agent's text stay line breaks.
- Every code span in backticks is highlighted and carries a **Kopieren** button
  that puts exactly its content — without the backticks — on the clipboard and
  confirms with "✓ kopiert". Code blocks get the button in their corner.
- Answers render the same way. Plain-text questions look as before.

Whether a question arrives with paragraphs and lists is up to the agent's text;
the button appears for anything it puts in backticks.

## Update or install

- **From 0.8.1–0.8.5:** check **Environment → Updates**, download 0.8.6, then
  install.
- **From 0.8.0 or earlier:** install the new version once from the
  [download page](/download/). These older versions lack the updater verification key.
- **Linux deb/rpm:** update through your package manager. In-app Linux updates
  apply to AppImage.

Packages cover macOS Apple Silicon, Windows x64 and Linux x86_64/arm64.
macOS packages are Developer ID signed and notarized. Update packages use verified
signatures on all four targets. Windows code signing is separate; SmartScreen may
still warn. Downloads are on the [0.8.6 release page](https://github.com/mhennemeyer/speccify/releases/tag/v0.8.6).

## Verification and scope

The board regression covers a question with paragraphs, a list, inline code and a
code block: structure, four copy buttons, the exact clipboard content and the
transient confirmation; a plain-text question stays a single paragraph without
buttons. The change applies to the question box of the spec inspector; the
workspace board and the web board are unchanged.

The published 0.8.5 was updated to the public 0.8.6 on macOS through the in-app
updater (30,650,645 bytes, signature verified, four windows restored, valid
Developer ID signature, notarized). All four public update URLs and the update
manifest were verified against an independent local rebuild. Windows and Linux
installation remain separate platform checks.
