## Automatic update checks

Speccify checks for updates at startup and daily. In **Environment → Updates**,
choose a six-hour, daily or weekly interval, turn automatic checks off, or check
manually. All windows share the same update state and download.

Review the version and release notes, then download the update. Progress,
cancellation and retry are available. Every update package is verified against
the signing key embedded in the app before installation becomes available.

## Install when your work is ready

Downloading does not restart the app. Installation is a separate action.
Before restarting, Speccify checks every open window. Open editors, changed
forms, saved drafts and running terminals or actions block installation.
Save your work, close the affected views and finish running processes, then retry.
A window that does not respond also blocks the restart.

## Install 0.8.1 once manually

**Versions 0.8.0 and earlier need this installer once:** they do not contain the
update verification key. Close Speccify and install 0.8.1 from the
[release page](https://github.com/mhennemeyer/speccify/releases/tag/v0.8.1)
or [download page](/download/). Future releases can use the new updater.

- **Windows x64:** use the setup executable; MSI is also available. Update
  signatures are separate from Windows code signing. SmartScreen may still warn.
- **macOS Apple Silicon:** Developer ID signed and notarized, macOS 11 or newer.
- **Linux x86_64 and arm64:** in-app updates for AppImage. Manage deb/rpm updates
  through your package manager. A graphical desktop and WebKitGTK 4.1 are required.

## Verification

The updater passed native signature and failure tests, UI checks and the
Windows/Linux CI suites. Release publication requires verified packages for all
four update targets before the complete update manifest is attached.
An actual installation from one released version to the next on each operating
system remains a separate acceptance step.

The itsdcloud board integration is available as a separate feature-branch
prototype, described in the [web-board guide](/web-board/).
