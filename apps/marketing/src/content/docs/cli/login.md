Authenticate the CLI against a Speccify registry via device-code flow.

## Usage

```bash
speccify login [OPTIONS]
```

## Options

| Option | Beschreibung |
| --- | --- |
| `--registry`, `-r` | Registry base URL (e.g. http://localhost:8001). |
| `--open-browser`, `--no-open-browser` | Whether to open the verification URL in a browser. |
| `--max-wait-seconds` | Abort polling after this many seconds. |
