Können wir schon manuell etwas testen / eine UI sehen?
Ja, drei UIs sind real und manuell startbar:
1. Browser-Playground (apps/web/) — die schickste UI
# Terminal A (Repo-Root):
uv run speccify-web-backend --host 127.0.0.1 --port 8000

# Terminal B:
cd apps/web/frontend
pnpm install
pnpm dev          # http://localhost:3000
Next.js 15 + Monaco-Editor, lädt die 5 Referenz-Specs aus registry-fixtures/, rendert sie offline gegen React/SwiftUI/Angular via Replay-Cache. Kein Live-LLM nötig.
2. Registry-Web-UI (registry/) — Django-Templates
cd registry
uv run python -m speccify_registry.manage migrate
uv run python -m speccify_registry.manage runserver
# http://127.0.0.1:8000  → Browse/Login/Tokens
3. CLI
uv run speccify lint specs/button.speccify.yaml
uv run speccify lock           # im example-workspace/
uv run speccify pull
uv run speccify whoami
Plus MCP-Server (speccify-mcp) für Coding-Agents — keine visuelle UI, aber funktional einsetzbar.
